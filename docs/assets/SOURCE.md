# Screenshot provenance

`arxiv-shelf-live.png` was captured on 2026-11-01 from the actual live site:
https://arxiv-shelf-library.rharriszzz.chatgpt.site

Capture method: the existing authenticated Google Chrome session, using the
computer-use `getScreenshot()` API. The live page showed 234 papers and a catalog
snapshot dated 2026-09-22. The OpenAI owner toolbar was hidden through its own
Hide toolbar control. No access settings were changed.

The browser-window capture was 3638 × 2460 pixels. It was cropped to the page
content at x=0, y=240, width=3608, height=2000, removing browser chrome, the right
scrollbar, and the bottom of the viewport. The crop was resized to 1800 × 997
pixels and saved as PNG using macOS `sips`. No application content was altered.
This is not a generated image, mockup, or local rendering of `dist/`.

`favicon.svg` is an independent copy of the existing application's icon.
